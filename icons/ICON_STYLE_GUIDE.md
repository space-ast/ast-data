# 图标风格规范

本规范定义了软件中所有图标的设计风格标准，确保视觉统一性和专业感。

---

## 1. 整体风格

- **扁平化设计**：无复杂渐变、无立体阴影、无高光效果
- **符号化表达**：高度抽象的几何图形，而非写实描绘
- **极简主义**：用最少的线条和形状表达核心概念
- **科技感**：清晰、锐利、现代的视觉语言

---

## 2. 色彩系统

| 类别 | 推荐色值 | 用途示例 |
|------|----------|----------|
| 主色调 | `#3399FF` (天蓝色) | 卫星、航天器、天线、传感器等航天核心对象 |
| 辅助色1 | `#33CC33` (鲜绿色) | 地面设施、雷达、接收机、地面车辆 |
| 辅助色2 | `#FF9933` (琥珀色) | 太阳、恒星、星群、覆盖范围定义 |
| 中性色 | `#5A8BAC` (蓝灰色) | 链、场景、目标、系统集合 |

> 所有颜色可在 ±10% 饱和度/亮度范围内微调，保持色系一致即可。

---

## 3. 图形规范

- **线条粗细**：统一的中等粗细轮廓线，约占图标尺寸的 1/16
- **圆角处理**：所有转角均使用适度圆角（半径 1-2px），避免尖锐直角
- **留白比例**：图标主体占画布的 70%-80%，四周保留均匀留白
- **对称优先**：尽可能采用中心对称或轴对称设计
- **线条闭合**：优先使用闭合路径，便于填充和识别

---

## 4. 构图原则

- **画布尺寸**：源文件使用 SVG 矢量格式，导出尺寸 32x32px 或 48x48px
- **视觉重心**：图形重心位于画布正中心
- **元素数量**：单个图标内图形元素不超过 3 个
- **识别度优先**：宁可简化细节，也要保证小尺寸下的可辨识性
- **像素对齐**：所有线条和锚点对齐像素网格，提升小尺寸清晰度

---

## 5. 各类对象设计范式

| 对象类型 | 设计范式 |
|----------|----------|
| **航天器/卫星** | 蓝色为主体，用简单的面板/天线结构示意 |
| **天体** | 行星用圆形+轨道线；太阳/恒星用放射状线条 |
| **地面设施** | 绿色为主体，塔状或雷达盘造型 |
| **系统/集合** | 用多个重复小元素组合示意 |
| **抽象概念** | （链、覆盖、场景等）用几何符号隐喻表达 |
| **运动/机动** | 用箭头或轨迹线示意方向性 |

---

## 6. 改进建议（基于原风格的优化）

1. **统一色板**：使用本规范定义的精确 HEX 色值，避免同色系内的色差
2. **矢量优先**：使用 SVG 作为源文件，便于导出多种尺寸和格式
3. **可访问性**：确保图标在灰度模式下仍有足够对比度
4. **命名规范**：图标文件名使用 PascalCase，如 `Satellite.png`、`GroundFacility.svg`

---
